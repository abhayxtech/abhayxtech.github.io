FAQ

Questions before you order

Do you need my hardware?

No. Send me your components list and wiring, and I'll write and test the code in a simulator or on my own boards.

Can you fix code I've already written?

Yes. Send me your code and explain what's going wrong, and I'll find and fix the problem.

Which package should I choose?

Quick Fix for small fixes or one sensor, Full Project for a complete project with up to 4 components, and IoT Project for WiFi projects with a live dashboard.

Do you build the physical hardware?

No. I deliver code, wiring diagrams and simulations, and you assemble the hardware yourself.

What if the code doesn't work on my setup?

Message me with the details and I'll fix it within your revisions. I make sure it works before closing the order.
